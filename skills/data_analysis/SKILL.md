# 数据分析步骤（skill: data_analysis）

按以下四步执行；每一步的中间结论都要写出来，不要直接跳到最终数字。

## 第一步：明确问题与口径

1. 把模糊提问转成可回答的问题：分析对象（谁/什么）、时间范围、粒度
   （按天/按会话/按用户）、成功判据。
2. 明确每个字段的口径：如"输入 token"是否含缓存部分、"一次会话"如何
   去重。口径不清时先向用户确认，不要静默假设。

## 第二步：数据体检（分析前必做）

1. 行数与时间覆盖：起止时间、是否有断档；明显缺失的分区先说明。
2. 空值与异常值：关键字段空值率；极端值（如单次用量超过总量 50%）单独
   标注，决定剔除还是保留并说明理由。
3. 重复数据：按业务键去重前先看重复规模，避免重复计数。

## 第三步：分层分析

1. 先看整体分布（总量 / 均值 / 中位数 / P90），再看分组对比（按模型、
   按工具、按时间）——分层后才谈趋势。
2. 对比要有基线：环比/同比或对照组；只有绝对值没有对比的结论降级为
   "观察"而非"结论"。
3. 数字要与原始记录抽查核对（至少抽 3 条对上账），防止统计口径错位。

## 第四步：结论与不确定性

1. 结论 = 数字 + 口径 + 对比基线，三者缺一不可；示例："会话均成本
   $0.021（含缓存读，10/01–10/31），环比下降 18%"。
2. 明确写出不确定性来源：样本量小的分组、口径估算、缺失数据的影响。
3. 给出下一步建议时区分"数据能支撑的"与"需要补充数据验证的"。
